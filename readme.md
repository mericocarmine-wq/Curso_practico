Resumen de lo aprendido:

- Entiendo la diferencia entre Git y GitHub.
- Git es un sistema de control de versiones que vive en mi ordenador.
- GitHub es un repositorio remoto donde sincronizo mi repositorio local mediante `git push`.
- Un commit existe primero en mi repositorio local.
- Un merge no es un conflicto; un conflicto puede aparecer durante un merge.
- Git puede fusionar automáticamente cambios cuando no afectan a la misma parte del código.
- Cuando dos desarrolladores modifican la misma zona del archivo, Git no puede decidir cuál es la intención correcta y requiere intervención humana.
- Entiendo que Git presenta cada commit como un snapshot del proyecto y que internamente reutiliza datos para no duplicar archivos innecesariamente.
